# 🎓 Student Management System Dashboard

A full-stack **Student Management Dashboard** designed to efficiently manage student records with a clean and user-friendly interface.
Built with simplicity, functionality… and a little extra motivation 😉.

---

## 🚀 Features

* ➕ Add new students
* 📋 View all student records
* ✏️ Update student details
* ❌ Delete student data
* 📊 Clean and responsive dashboard UI

---

## 🛠️ Tech Stack

**Frontend:**

*React.js / Tailwind

**Backend:**

* Node.js / Express

**Database:**

* MongoDB 
---

## 📁 Project Structure

```
student-management-system/
│
├── frontend/    # UI / Client side
├── backend/     # Server / API
└── README.md
```

---

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/student-management-system.git
```

### 2. Navigate to project folder

```
cd student-management-system
```

### 3. Install dependencies

**Frontend:**

```
cd frontend
npm install
npm start
```

**Backend:**

```
cd backend
npm install
node server.js
```

---

## 🌐 Usage

* Open the app in your browser
* Add, update, and manage student records easily
* Simple CRUD operations through dashboard
